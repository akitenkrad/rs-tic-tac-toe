# 遊び方

## ルール

2 人が交互に 3 × 3 の盤へ自分の印を置きます．先手が **X**，後手が **O** です．縦・横・斜めのいずれかに自分の印を 3 つ先に並べた方が勝ちです．どのラインもそろわないまま盤が埋まったら引き分けです．

## マスの呼び方

マスは 2 通りの方法で指定できます．画面上でも [棋譜ファイル](replay.ja.md) でも同じです．

```text
    a    b    c          1  2  3
1   a1   b1   c1         4  5  6
2   a2   b2   c2         7  8  9
3   a3   b3   c3
```

- 座標: 列の文字 `a`〜`c`（左から右）と行の数字 `1`〜`3`（上から下）．
- 数字: 左上から読み順に `1`〜`9`．テンキーの配置とは **違う** ので注意してください．

## 対局の開始

`rs-tic-tac-toe`（または `cargo run --release`）を実行するとタイトル画面が開きます．

| キー | 設定 | 値 |
|---|---|---|
| `d` | 難易度 | やさしい / ふつう / 最強 |
| `f` | 先手（X を持つ） | あなた / CPU |
| `l` | 言語 | English / 日本語 |
| `Enter` / `Space` | 開始 | |
| `q` | 終了 | |

CPU は難易度に応じた確率（やさしい 20 %，ふつう 65 %）で最善手（[必勝法と完全読み](strategy.ja.md) を参照）の中から 1 つを選び，それ以外のときは空いているマスにランダムに置きます．最強では常に最善手を指すので，決して負けません．

## 対局中の操作

| キー | 動作 |
|---|---|
| `←` `↑` `↓` `→` | カーソルを動かす |
| `1`-`9` | そのマスを選ぶ（同じ数字をもう一度押すか `Enter` で置く） |
| `Enter` / `Space` | 選んだマスに印を置く |
| `h` | ヒント: 最善手を強調表示する．引き分けか負けしか残っていなければその旨を表示 |
| `e` | 評価パネルの表示切替 |
| `s` | 現在の対局を棋譜ファイルに保存（[リプレイ](replay.ja.md) を参照） |
| `n` | 新しい対局 |
| `t` / `Esc` | タイトルへ |
| `q` / `Ctrl-C` | 終了 |

CPU は選んだマスを一瞬強調してから印を置きます．置いた印はふわりと現れます．勝負がつくと勝ちラインが点滅し，あなたが勝つと紙吹雪，負けると雨が降ります．サイドパネルには，このセッションの勝・敗・分を表示します．

## 評価パネル

`e` を押すと，空いている各マスに「そこへ置いた場合の結果」を表示します．以後は双方が最善を尽くすと仮定し，手番側から見た結果です．

- **勝ち n** — 勝てる．この手を含めて `n` 手で終局する（`勝ち 1` はその場で勝ち）．
- **引分** — 双方が最善を尽くすと引き分けになる．
- **負け n** — 相手が勝ちを強制でき，`n` 手で終局する．

## 表示言語

画面の表示は既定で英語です．タイトル画面で `l` を押すか，`--lang ja` を付けて起動すると日本語になります（`replay` でも使えます）．

## 端末の要件

- **80 × 24** 以上の端末サイズが必要です．小さいと，広げるよう案内が出ます．
- True Color（24bit）対応の端末を推奨します．WezTerm，iTerm2，kitty，Alacritty など．
- 印は背景色付きのセルで描くので，特別なフォントは要りません．
- 日本語環境で罫線の幅が崩れる場合は，端末の「East Asian Ambiguous 文字の幅」を 1（半角）に設定してください．
