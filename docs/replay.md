# Game records and replay

rs-tic-tac-toe can replay a game from a plain-text record file (`.tttrec`). Records can be written by hand, generated by another program, or saved from a game you played. Replay mode is also designed for screen recording: it plays back automatically at a fixed pace and can quit by itself at the end.

## Replaying a record

```sh
rs-tic-tac-toe replay examples/records/x-wins.tttrec
```

| Option | Description |
|---|---|
| `<FILE>` | Record file, or `-` to read from standard input |
| `--interval <INTERVAL>` | Automatic playback interval in milliseconds (default `1500`; values below the 480 ms placement animation are raised to 480) |
| `--paused` | Start playback paused |
| `--exit-on-end` | Exit three seconds after reaching a finished record's end |
| `--print` | Print the replay as text instead of starting the TUI |

If the file cannot be read or contains an error, rs-tic-tac-toe prints the problem (with its line number) to standard error and exits with status 1 before the TUI starts.

### Controls in replay mode

| Key | Action |
|---|---|
| `Space` | Play / pause |
| `→` / `l` | Step forward one move (with animation) |
| `←` / `h` | Step back one move |
| `Home` / `g` | Jump to the start |
| `End` / `G` | Jump to the end |
| `+` / `-` | Faster / slower (250 ms per step) |
| `e` | Toggle the evaluation panel |
| `q` / `Esc` / `Ctrl-C` | Quit |

The status bar shows whether playback is running, the move number (`k/N`) and the current interval. When the last move ends the game, the result panel announces the winner by name or a draw; a record that stops mid-game ends with "end of record" (棋譜の終わり) instead.

### Text output

`--print` checks the record and prints each move with the resulting board, which is handy for verifying a file or for scripting:

```sh
rs-tic-tac-toe replay examples/records/x-wins.tttrec --print
```

```text
手数 1: Alice X a1
X . .
. . .
. . .
...
手数 7: Alice X b3
X . O
O O .
X X X
勝者: Alice
```

## Saving your own games

During a game or on the result screen, press `s` to save the current game as `ttt-<unix-seconds>.tttrec`. Files go to the current directory unless you start rs-tic-tac-toe with `--record-dir <DIR>`:

```sh
rs-tic-tac-toe --record-dir ~/ttt-records
```

Saved records use the default names あなた (you) and CPU; edit the `human` / `cpu` lines to rename the players.

## The `.tttrec` format

A record is UTF-8 text: a header of `key = value` lines followed by one move per line.

```text
# rs-tic-tac-toe record v1
first = human      # human | cpu   (default: human; the first player plays X)
human = Alice      # optional display name of the "human" side (default: あなた)
cpu   = Bob        # optional display name of the "cpu" side   (default: CPU)

b2                 # move: a cell as a coordinate a1..c3 ...
A1                 # ... case-insensitive ...
9                  # ... or a number 1..9 in reading order (9 = c3)
```

Rules:

- `#` starts a comment; blank lines are ignored.
- Header keys may only appear before the first move. Unknown or duplicated keys are errors.
- Moves alternate starting with `first`, who plays X. See [cell names](gameplay.md#cell-names) for the two notations.
- `human` and `cpu` are just the two sides; in replay they are shown with the names you give them, so a record can describe any two players.
- Placing a mark on an occupied cell, or any move after the game has ended, is an error. A record may stop before the game ends.

Three sample records live in [`examples/records/`](../examples/records/):

| File | Contents |
|---|---|
| `perfect-draw.tttrec` | Perfect play from both sides, ending in a draw |
| `x-wins.tttrec` | X wins with a fork |
| `unfinished.tttrec` | A record that stops mid-game |

## Recording a video

Replay mode makes a game reproducible, so you can record the same game as often as you like. Make sure the recording terminal is at least 80 × 24 cells.

With [asciinema](https://asciinema.org):

```sh
asciinema rec -c "rs-tic-tac-toe replay game.tttrec --exit-on-end" ttt.cast
```

With [VHS](https://github.com/charmbracelet/vhs), a tape file such as:

```text
Output ttt.gif
Set Width 1300
Set Height 650
Type "rs-tic-tac-toe replay game.tttrec --interval 1200 --exit-on-end"
Enter
Sleep 15s
```

`--exit-on-end` leaves the final board and result on screen for three seconds and then quits, so the recording ends cleanly. Use `--paused` instead if you want to step through the game by hand while recording.
